# Revues

Constats datés sur l'ensemble du projet (architecture, sécurité…), distincts des décisions (`adr/`) et des spécifications (`specs/`). Une revue ne modifie pas le code : chaque recommandation est triée avec l'utilisatrice, puis devient une fiche todo, un ADR, ou un abandon motivé noté dans le rapport.

Nom des fichiers : `AAAA-MM-JJ-sujet.md`.
