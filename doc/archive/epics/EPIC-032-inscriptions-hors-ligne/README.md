# EPIC-032 : Page Inscriptions lisible hors ligne

## Objectif

[Fiche](../../todo/inscriptions-hors-ligne.md), relevée par la revue de la PR [#95](https://github.com/Kethryweryn/limbus/pull/95). Sur le lieu du GN, sans réseau, l'équipe consulte qui est inscrit, retenu ou en attente, et le détail d'une inscription. [SPEC-010](../../../specs/SPEC-010-hors-ligne.md), R1.

## Décisions

2026-11-02, choix de l'utilisatrice :

- le détail d'une inscription ouverte avec le réseau est gardé en entier, allergies et affinités comprises ;
- la sélection se lit aussi hors ligne : retenus, listes d'attente, vivier, journal des tirages ;
- les boutons d'action restent visibles, comme ailleurs : hors ligne, un clic échoue avec un message.
