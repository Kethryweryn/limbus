# Retours du cahier de tests fonctionnels

## Besoin

L'utilisatrice déroule un cahier de tests sur les jeux de test ([EPIC-044](../epics/EPIC-044-jeux-de-test/README.md)). Ce qu'elle y signale change ce que les personnes voient : chaque retour retenu devient une US.

## Proposition

Un epic ouvert pendant ces essais, [EPIC-045](../epics/EPIC-045-retours-du-cahier-de-tests/README.md), avec une US par retour, livrées par petits lots.

## Découpage envisagé

Une PR par lot de retours, dans l'ordre où ils bloquent les essais.

## Points à trancher

Aucun. Le 2026-11-06, l'utilisatrice demande de corriger d'abord les retours déjà signalés, car l'un d'eux bloque ses essais comme participante.
